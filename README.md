# Calculadora de IMC

## Projeto criado com ReactJs e Typescript. Aplicação onde a fim de calcular seu Índice de Massa Corpórea

# Funcionalidades

* Adicionar peso e altura

* Retorno do valor do IMC indicando também se está normal ou não

* Limpar campo

# Tecnologias Utilizadas

* ReactJS - Para construção da interface

* CSS - Para estilização da interface

* React Hooks - Para gerenciamento de estado

# Conceitos Abordados

Componentização


# Como utilizar

1- Clone o projeto
`git@github.com:helen-andrade/imc-calculator-reactjs.git`

2- Instale as dependências
`npm i`

3- Rode o script de desenvolvimento
`npm run dev`
